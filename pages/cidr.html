Understanding CIDR Notation

What is CIDR?

CIDR (Classless Inter-Domain Routing) is a notation for representing IP addresses and their associated network masks. Format: IP_ADDRESS/PREFIX where PREFIX (0-32) is the number of bits used for the network.

CIDR Prefix

The prefix number indicates how many bits from the left are used for the network portion. For example, /24 means the first 24 bits are the network, leaving 8 bits (256 addresses) for hosts.

Subnet Mask

Traditional notation showing network and host portions in dotted decimal. Each octet (8 bits) can be 0-255. Network bits are represented as 1s, host bits as 0s in binary.

Wildcard Mask

Inverse of subnet mask. Where subnet mask has 1s, wildcard has 0s, and vice versa. Used in access control lists and some routing protocols.

Network Size

Total addresses = 2^(32-PREFIX). For /24: 2^(32-24) = 2^8 = 256 total addresses. Usable hosts = total - 2 (network and broadcast).

Common Uses

CIDR is used in routing protocols (BGP, OSPF), AWS subnetting, DNS, firewall rules, and modern network design for efficient IP allocation.
