About Subnet Calculation

Network Address

The first address in a subnet. It identifies the network and cannot be assigned to a host. Calculated by performing a bitwise AND between the IP address and subnet mask.

Broadcast Address

The last address in a subnet used to send messages to all hosts on the network. Calculated by performing a bitwise OR between the network address and the inverted subnet mask.

Usable Hosts

All addresses between the network address and broadcast address (excluding both). The number of usable hosts is 2^(32-prefix) - 2.

CIDR Notation

Classless Inter-Domain Routing notation represents a network and its subnet mask. Format: IP/PREFIX where PREFIX is the number of bits used for the network (0-32).

Wildcard Mask

The inverse of a subnet mask. Used in access control lists and routing. Calculated as NOT (subnet mask) in binary.

Common Subnet Masks

/24 (255.255.255.0): 254 hosts | /25 (255.255.255.128): 126 hosts | /26 (255.255.255.192): 62 hosts
